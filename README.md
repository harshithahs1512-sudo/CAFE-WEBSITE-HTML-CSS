# CAFE-WEBSITE-HTML-CSS
A simple cafe website created using HTML and external CSS,featuring a menu,food images, special offers and an order form
<br>
Mevi Smart Cafe 

Mevi Smart Cafe is a simple cafe website created using HTML and External CSS as part of my web development learning

The website includes:

- Home section
- About Us
- Special Offers
- Food Menu with Images
- Customer Invoice
- Order Form
- Contact Information

Technologies Used

- HTML
- CSS(External Stylesheet)

Features

- Simple and user-friendly design
- Food images with descriptions and prices
- Navigation links to different sections
- Basic customer order form
- Separate HTML and CSS files

Purpose

This project helped me practise HTML tags,tables,forms,images,links and basic CSS styling

Created as a beginner-level web development project.
